课程要求对照

类别要求在网页里哪里看
基本并查集 + Kruskal / Prim 生成完美迷宫（Prim 用堆）算法实验室 → 生成算法；环路比例保持 0% 即完美迷宫，统计里拆墙次数恰好 N−1
基本BFS 求最短路径、DFS 搜索算法实验室 → 求解算法
基本搜索算法都要有递归和非递归（显式栈 / 队列）两种写法求解算法下拉框里四种都有；求解算法对比会自动验证递归版与非递归版逐格一致
基本逐步显示搜索路径算法实验室 → 播放 / 单步 / 跳到结尾，热力图显示离起点的距离
额外更好的交互式界面闯关冒险：玩家自己走迷宫，再和 BFS 最短路线对比评星
额外可视化比较不同生成算法生成算法对比：并排同步播放 + 多样本统计
额外性能（时间 / 空间复杂度）分析两个对比页给出实测耗时；完整测试与报告见仓库 test/ 与 docs/

网页是怎么跑起来的

C++ 算法源码
src/maze_generator.cpp（李婷婷：并查集、Kruskal、Prim）
src/maze_solver.cpp（方雨婷：BFS、DFS 各两种写法）
▼
编译成 WebAssembly
用 clang（wasi-sdk）把上面两份源码原样编译，web/wasm_api.cpp 只负责把结果交给网页，不改算法
▼
浏览器里运行
网页（JavaScript + Canvas）只负责画图和交互；每次生成、求解都是在调用这段 C++ 代码

分工

李婷婷迷宫生成：并查集、Kruskal、Prim（堆）、种子与环路
方雨婷迷宫求解：BFS / DFS 递归与非递归；Qt 界面与网页界面
白荷初正确性测试、性能测试、对比分析与报告

同一份 C++ 代码也有 Qt 桌面版（仓库根目录 CMake 工程）。两边功能一致，迷宫的随机结果因标准库实现不同可能不一样。
